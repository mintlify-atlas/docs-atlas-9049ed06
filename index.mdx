ZFS Backup Blob is an open-source command-line tool that automates the process of backing up ZFS snapshots to any S3-compatible blob storage. It supports full and incremental backups, optional AES-256-GCM encryption, bandwidth throttling, and configurable trim policies to manage storage retention — both locally and remotely.

## How it works

ZFS Backup Blob uses a **pipeline-style stage configuration**: data flows from the ZFS source through optional middleware stages (encryption, throttling) into an S3-compatible sink. You define these stages in a single YAML config file.

<Steps>
  <Step title="Install the binary">
    Download the latest release from GitHub and place it on your `PATH`.
  </Step>
  <Step title="Write a config file">
    Create `~/.bbackup.yaml` defining your S3 bucket and any optional middleware stages.
  </Step>
  <Step title="Register volumes">
    Add ZFS volumes to a backup group with `zfs-backup-blob group add-volume`.
  </Step>
  <Step title="Snapshot and sync">
    Create snapshots with `group snapshot`, then upload them with `group sync`. Schedule both commands with cron for fully automated backups.
  </Step>
</Steps>

## Key features

<CardGroup cols={2}>
  <Card title="Full & Incremental Backups" icon="layer-group">
    Choose between full snapshots or space-efficient incremental backups that store only the delta from the previous snapshot.
  </Card>
  <Card title="AES-256-GCM Encryption" icon="lock">
    Add a `crypt` stage to encrypt all backup data end-to-end before it leaves your machine.
  </Card>
  <Card title="Bandwidth Throttling" icon="gauge">
    Insert a `throttle` stage to cap upload and download speeds, preventing backups from saturating your network.
  </Card>
  <Card title="S3-Compatible Storage" icon="cloud">
    Works with AWS S3, Backblaze B2, MinIO, and any S3-compatible API via `baseEndpoint` and `usePathStyle` options.
  </Card>
  <Card title="Volume Groups" icon="folder-tree">
    Group multiple ZFS volumes together and snapshot or sync them all with a single command.
  </Card>
  <Card title="Trim Policies" icon="scissors">
    Define simple string policies (e.g. `IFIFIF`) to automatically prune old backups from both local storage and the remote blob store.
  </Card>
</CardGroup>
